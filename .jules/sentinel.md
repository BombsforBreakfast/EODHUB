## 2025-05-18 - Fix JSON-LD Injection Vulnerability in Root Layout
**Vulnerability:** A static JSON-LD object was serialized using `JSON.stringify` and directly passed to `dangerouslySetInnerHTML` in the `<script type="application/ld+json">` tag within the root layout (`app/layout.tsx`) without escaping angle brackets (`<`).
**Learning:** Although the currently injected JSON payload consists of static, hardcoded strings without user input, the failure to escape angle brackets when passing serialized JSON into a `<script>` tag creates a latent architectural vulnerability. If any dynamically sourced or user-controlled properties (such as a search string query) are later added to this JSON-LD schema, an attacker could inject arbitrary scripts (e.g., `</script><script>alert('XSS')</script>`), leading to a Cross-Site Scripting (XSS) attack.
**Prevention:** Whenever injecting JSON objects into `<script>` tags using `dangerouslySetInnerHTML`, always sanitize the serialized JSON output using `.replace(/</g, "\\u003c")`. Ensure the double backslash is used in the source file so it compiles down to the literal string representation `\u003c`, which the browser will safely parse as `<` within the JSON without executing it as HTML.
