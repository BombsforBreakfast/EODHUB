## 2025-02-23 - [XSS vulnerability in application/ld+json injection]
**Vulnerability:** In `app/layout.tsx`, a JSON object is serialized using `JSON.stringify` and injected directly into a `<script type="application/ld+json">` tag using `dangerouslySetInnerHTML`. The serialization does not escape `<` characters. If any field within the JSON (such as the `search_term_string` dynamically injected via URL or data later on, though currently hardcoded) contained a `</script>` tag followed by malicious JS, it would break out of the script context and result in Cross-Site Scripting (XSS).
**Learning:** React's `dangerouslySetInnerHTML` does not automatically HTML-encode or escape values. When embedding JSON directly into an HTML document within a script tag, standard `JSON.stringify` output is not safe against HTML parser escapes like `</script>`.
**Prevention:** Always sanitize JSON injected into HTML contexts by replacing `<` with `\u003c` (using `.replace(/</g, "\\u003c")`) or using safe JSON serialization libraries.
